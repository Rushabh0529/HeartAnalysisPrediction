# Heart Disease Risk Prediction using Machine Learning

This project applies machine learning techniques to analyze health data and predict the risk of cardiovascular (heart) disease. The goal is to help identify early warning signs and provide actionable insights for preventive healthcare.

## 📁 Project Files

- `heart_analysis_prediction.ipynb`: Main notebook for data preprocessing, exploratory data analysis (EDA), and building ML models to predict heart disease.
- `work.ipynb`: Supplementary notebook for experimentation or additional modeling (may include tuning or comparisons).

## ⚙️ Technologies Used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (Logistic Regression, Random Forest, Gradient Boosting)
- Jupyter Notebook

## ✅ Key Features

- Cleaned and wrangled a health dataset from the UCI Machine Learning Repository
- Performed EDA with visualizations like boxplots and bar plots
- Built and evaluated classification models
- Identified logistic regression as the most effective model
- Planned hyperparameter tuning and feature exploration for further improvements
- Provided insights and early detection strategies to help reduce cardiovascular mortality

## 📊 Results

The logistic regression model showed the highest performance on evaluation metrics and was selected as the best candidate for predicting heart disease risk.
